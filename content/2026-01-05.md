小檢查：你的 Windows 有沒有內建「winget」（Windows 的官方套件安裝工具）。  
請你在同一個 cmd 視窗，貼上這行按 Enter，然後把結果整行貼回來：

`winget --version`

用 winget 安裝 Git。

請在同一個 cmd 視窗，直接複製貼上下面這行，按 Enter：

`winget install --id Git.Git -e --source winget`

不要關掉 cmd，立刻在同一個視窗再輸入這行驗證：

`git --version`

把「安裝過程最後的訊息」以及 `git --version` 的結果整段貼回來。

如果 `git --version` 仍然顯示「不是內部或外部命令」，也沒關係，直接貼錯誤字樣，我會帶你用最短路徑修正（通常是 PATH 尚未刷新，重開 cmd 或補環境變數即可）。

步驟 1（建立 Quartz 專案資料夾並下載 Quartz 原始碼）  
請在 cmd 視窗依序貼上這三行（每行貼上後按 Enter）：

`cd /d C:\Users\user\Documents git clone https://github.com/jackyzha0/quartz.git LawGarden cd LawGarden`

- `git clone ...` 會跑一串下載訊息，最後通常會看到類似「done」之類的完成訊息（重點是不要停在紅字錯誤）。

    `C:\Users\user\Documents\LawGarden>`
