# 使用說明（第一次必看）

這是一組「新增內容包」，你可以直接把整包解壓後，將資料夾合併到你原本的 Vault。

核心流程（建議固定照做）

1. 把原始資料先丟到「00_收件匣」。
2. 用 Templater 模板落地成骨架。
3. 需要翻譯／摘要／改稿時，把「原文」貼到 ChatGPT 讓它整理，再貼回 Obsidian。
4. 整理完成後歸檔到：04_法條庫／05_判決庫／06_議題庫／07_文章庫／90_程式學習。

模板位置

02_學習筆記/系統/_Templates

怎麼插入模板

在 Obsidian 開「命令面板」，請用 Templater 的指令（不是 Obsidian 內建 Templates）：

- Templater: Open insert template modal
- 若看到 <%% ... %%> 沒被替換，再跑一次：Templater: Replace templates in the active file

排錯（Template parsing error）

- 先用 _Templates/_TEST.md 測試。
- 若 _TEST 也錯：通常是 Safe mode 沒關或 Templater 沒有 Enabled。
