# 使用說明（第一次必看）

這份 Vault 已加上「收件匣＋法條庫＋判決庫＋議題庫＋文章庫＋程式學習」資料夾與一組極簡模板。

核心流程（建議固定照做）

1. 把原始資料先丟到「收件匣」：法條、判決摘錄、題目、英文資料、程式碼、錯誤訊息都可以。
2. 用模板把內容落地：先有骨架，再慢慢補。
3. 需要整理成好讀版本時，把「原文」貼到 ChatGPT，請它做翻譯／摘要／重點／你觀點的改稿。
4. 整理完成後再歸檔到：法條庫／判決庫／議題庫／文章庫／程式學習。

模板在哪裡

- 位置：02_學習筆記／系統／_Templates
- 主要模板（Templater）：
  - 收件匣_貼上即落地
  - 法條_落地
  - 判決_落地
  - 議題_落地
  - 程式筆記_雙語落地

怎麼用模板（用中文指令就能找）

1. 在 Obsidian 開「命令面板」（Command Palette）
2. 輸入並選：Templater: Open insert template modal
3. 挑一個模板插入
4. 如果你是把模板插入到「既有檔案」而且看到 <%% ... %%> 沒有被替換，請再跑一次：Templater: Replace templates in the active file

排錯（你之前遇到的 Template parsing error）

- 先用 _Templates/_TEST.md 測試。
  - 若 _TEST 也錯：通常是社群外掛未啟用（Safe mode 沒關）或 Templater 沒有 Enabled。
  - 若 _TEST 正常：代表某個模板內容有語法破損，從最簡模板開始用，逐步加回。

建議你先把三個模板用熟：收件匣_貼上即落地／法條_落地／程式筆記_雙語落地。
