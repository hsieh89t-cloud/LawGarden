# 第一次必看（3 分鐘）

1. Obsidian → 設定 → 社群外掛（Community plugins）
   - 確認已啟用 Templater。

2. Obsidian → 設定 → Templater → Template folder location
   - 設為：02_學習筆記/系統/_Templates

3. 建議新手的使用方式
   - 先複製一段文字
   - 新建一個空白筆記
   - 命令面板 → Templater: Open insert template modal
   - 選「收件匣_貼上即落地」或「程式筆記_雙語落地」

4. 你看得到「黑黑的程式碼」的原因
   - 你用了 Obsidian 內建的 Templates 插入，而不是 Templater 的插入。
   - 請用「Templater: ...」開頭的指令。

5. 只要想要更好讀
   - 把「原文」段落丟給 GPT：請它翻譯／摘要／抓爭點
   - 再把整理後內容貼回筆記。
